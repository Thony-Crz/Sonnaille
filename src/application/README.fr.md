# application

Les cas d'usage (préparer une sortie, signaler une observation, consulter une zone) et les **ports** : les interfaces dont ils ont besoin pour obtenir des données ou piloter l'affichage (dépôt de zones, lecteur de GPX, vue de carte…).

- Dépend seulement de `domain`. Aucune bibliothèque externe.
- Testée avec des implémentations en mémoire des ports.
